MERCENARY — LVL & REBOOT CALCULATOR

This calculator is used to simulate mercenary progression based on available Mercenary Points (MP).

After entering the data (amount of mercenary points, mercenary rarity, current reboot, and current level), the tool:
• step-by-step simulates mercenary progression
• automatically performs leveling and reboots at the optimal moments
• shows the maximum possible Reboot (R) and Level (L) that can be achieved
• calculates spent MP, remaining MP, and total Credits used

The results are displayed in a table divided by reboots, making it easy to see:
• how much each stage of progression cost
• how much MP remained after each reboot
• how many Credits were spent at each stage
Costs shown are cumulative (1 → n).

At the top, a summary result is also shown, for example:
R 0 & Lvl 1 → R 2 & Lvl 14 | Leftover MP: 210 | Total Credits: 144,900

In short:
This tool lets you quickly check how far you can progress your mercenary and how much it will cost, without manual calculations.

LVL & REBOOTS TABLES

A set of reference tables used to check legendary mercenary leveling costs and reboot-related thresholds.

The tables show how many Mercenary Points (MP) and Credits are required to reach specific levels, divided by mercenary rarity: Common, Rare, Epic, and Legendary.

You can switch between two table modes:
• Cumulative (1 → n) — shows the total cost of upgrading a mercenary from level 1 to the selected level.
• Per-Level (n → n+1) — shows the cost of a single mercenary upgrade from one level to the next level.

Each mode contains two tables:
• Level Up — Mercenary Points, showing how many mercenary points are needed for a given level.
• Level Up — Credits, showing how many credits are needed for a given level.

Rows highlighted in orange indicate levels at which a reboot becomes available.

Use these tables when you want to manually compare upgrade costs, check how much a specific level costs, or better understand what data the calculator uses when calculating levels and reboots.

SERUM BOOSTS TABLES

This table shows the cost of upgrading mercenary using Super Serum.

For each upgrade step (+0 → +1, +1 → +2, etc.), the table displays how much Super Serum is required to perform the upgrade.

The cost depends on the mercenary level and is divided into level ranges:
Lvl 1–5, Lvl 6–10, Lvl 11–15, Lvl 16–20, Lvl 21–26, Lvl 27–31

Each tab represents a different mercenary rarity:
Common, Rare, Epic, and Legendary.

The values in the table indicate how much Super Serum is required for a single Boost upgrade at that level range.
