RELATIONSHIP — GIFTS CALCULATOR

This interactive table helps you calculate relationship progress for each mercenary.

Enter your current relationship points in the Points column to automatically calculate the mercenary’s relationship Level and the Required Points needed to reach the Level 20 goal — 35,100 points.

The Best Points column shows how many points you can gain using only the mercenary’s favorite gifts, while the Total Points column shows the full value of all owned gifts, including non-favorite gifts counted with lower point values.

In the Data panel, you can enter how many gifts of each type you currently own. Changing any value automatically recalculates Best Points and Total Points for all mercenaries.

You can search mercenaries by name, sort the table by clicking supported headers, and show or hide the Data panel to give the table more space.

Entered data is saved automatically locally and in the page URL, so the calculator state can be restored after refreshing the page or shared with others.
