Before Messaging

How to Make Your Message Helpful

Include the page or tool name

For example: “Favourite Gifts”, “Gifts Calculator”, “Lvl Calculator” or “Wiki”.

Describe the issue clearly

If something is wrong, explain what happened and what should be changed.

Add a screenshot if useful

Screenshots make it much easier to understand visual bugs or wrong table data.
